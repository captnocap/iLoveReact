# CENSUS — /compose (e2e walked 2026-06-06, session CENSUS-VEH-0606-compose)
Status today: `/compose` is the decal editor for billboards/signs/graffiti-style textures: it edits a decal document made of rect/text/image nodes, previews it on a 2D stage and optional 3D billboard, and materializes the decal as a stored material. Live route render was captured with `tools/rjit shot hmsc-int --route /compose --out /tmp/census-compose.png`; headless witness click automation did not activate in this shipped binary, so source-backed click/drag rows are marked in Unverified-live rows. UNPLANNED rows: none found; decal/material authoring is PENDING `sources.ts` step 7, while the resulting stored texture can already appear as a paintable workbench material row.
