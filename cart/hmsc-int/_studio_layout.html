The studio tile, adaptive — wide → flexible

The tile lives in a sliding-divider quad, so it can't assume width. Here it reflows off its own measured width (CSS container queries), so the same component works whether its quad is huge or pinched. Drag the ◢ corner of the tile, or snap to a preset. As it narrows, side columns fold into on-demand drawers — nothing is lost, it just changes posture. The four faculties (tree · preview · properties · AI) all survive.
