## Current boundaries

- This migration remains side-by-side. No `scripts/*` entrypoint has been converted into a shim.
- `tools/rjit.js` is generated from `cli/main.ts` with `tools/esbuild`.
- Existing dirty worktree changes outside `cli/`, `tools/rjit`, and `tools/rjit.js` were not modified by this progress file.
- Exception (slice 21): `bake-geometry` is net-new capability whose runtime half necessarily lives outside `cli/` — `runtime/geometries/{intern.ts,_baked.generated.ts,BAKE.md}` were added/edited and committed separately on `main` (commit 3972d7dda). The `cli/` command itself stays in this untracked tree for the migration's own commit.
